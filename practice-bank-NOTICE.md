# 1,000 N2/N3 vocabulary practice items — source and license

## What this is
This website adds **1,000 generated, four-option JLPT-style vocabulary exercises** (500 N2 + 500 N3; 700 kanji-reading + 300 kana-to-kanji writing questions) built from an open vocabulary list. These are **not official JLPT past-exam questions**. Difficulty tags are community approximations, not official JLPT lists.

The original 18-question quiz remains available; the new dataset is additive. Distractors and the Chinese-language explanation templates were generated for this website. Source word readings and English meanings are provided as-is and can still contain errors; report any questionable alternative reading. Chinese sentence-by-sentence translations are not included in the imported items; English glosses are labeled as such.

## Source, credits and modifications

- Vocabulary source (MIT): https://github.com/allenlu2009/japanese-learning-datasets
- Files used: vocabulary/n2.json and vocabulary/n3.json
- Original vocabulary upstream (MIT): https://github.com/elzup/jlpt-word-list
- Changes: selected 1,000 distinct entries containing kanji, removed duplicate spellings / invalid readings, distributed levels evenly, constructed the multiple-choice question prompts, distractors, answer positions, explanations and app display.
- Date integrated: 2026-10-16
